# 📚 NFSU DFIS Study Material Repository

Welcome to the **NFSU DFIS Study Material Repository**!
This repository is a centralized collection of academic resources shared by seniors and super-seniors for students of **Digital Forensics & Information Security (DFIS)** at **National Forensic Sciences University (NFSU)**.

📍 **All notes and materials in this repository are specifically from the NFSU Goa Campus.**

It is specially curated for the batches:
- 🎓 2024–2026
- 🎓 2025–2027

This repository is built to help students with structured learning, revision, and exam preparation.

---

## 🎯 Purpose of This Repository

✅ Help juniors access authentic and useful study material  
✅ Preserve the knowledge shared by seniors  
✅ Improve academic performance  
✅ Build a long-term learning archive for DFIS students

## 📥 How to Use

1. Clone the Repository:
git clone https://github.com/neelvaria/NFSU_DFIS_StudyMaterial.git

2. Open the Project:
cd NFSU_DFIS_StudyMaterial

3. Browse by Batch  
Open your batch folder and access subject-wise resources.

---

## 🤝 Contribution Guidelines

1. Fork this repository  
2. Add your files in the correct batch folder  
3. Use proper file naming format:
SubjectCode_SubjectName_Topic.pdf  
4. Commit and create a Pull Request  

Rules:
- No copyrighted books  
- No personal or confidential data  
- Only clean and readable files  
- Give credit if content is not originally yours
